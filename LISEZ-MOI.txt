HINOENMA — OBSESSION DE POSSESSION — ÉDITION CINÉMATOGRAPHIQUE

Ouvrir index.html avec Chrome, Edge ou Firefox après avoir décompressé TOUT le dossier.
Site entièrement autonome, sans serveur ni téléchargement supplémentaire.

Pour modifier le récit : chapters.js (chaque chapitre contient title, period, images, track, body).
Pour modifier la fiche et les paroles de Frite : index.html.
Pour modifier les techniques et l'interaction : app.js.
Pour retoucher les cadres / les animations : style.css, section CINEMATIC REMASTER à la fin.

VERSIONNEMENT AUTOMATIQUE POUR GITHUB PAGES — V7
--------------------------------------------------
Pour publier une modification (texte, image, musique, CSS, etc.) :
1. Modifie tes fichiers normalement.
2. Sous Windows, double-clique sur PREPARER_PUBLICATION.bat.
3. Publie les fichiers modifies dans ton depot GitHub (GitHub Desktop : Commit puis Push).
4. Quand GitHub Pages a fini son deploiement, recharge le site.

Ce script utilise uniquement Python 3. Il ajoute une empreinte du CONTENU
aux URLs (ex. style.css?v=...), sans renommer les fichiers.
Les nouvelles versions d'images, de musiques, de chapitres et de code sont
rechargees, tandis que les fichiers inchanges profitent du cache.

Il est sans risque de relancer le script plusieurs fois : sans changement,
les numeros de version restent identiques.

IMPORTANT : Si tu modifies directement les fichiers dans le navigateur GitHub,
ce script local ne s'execute pas automatiquement sur le serveur.
Dans ce cas, utilise GitHub Desktop pour publier la version preparee,
ou il faudra mettre en place GitHub Actions pour automatiser cette etape.
Un deploiement GitHub Pages peut aussi prendre quelques minutes.
